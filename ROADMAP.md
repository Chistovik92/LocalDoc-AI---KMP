# План версий

## 1.6.5 — улучшение UI и виджет

- [ ] UI: исправить «расползающиеся» кнопки (проверка всех экранов на эмуляторе, узкие ширины, крупный шрифт)
- [ ] UI (со скриншотов пользователя): кнопка «Слушать» в карточке «Продолжить чтение» сжимается в круг с вертикальным
      текстом; плавающая «Добавить» перекрывает плитки книг; обрезанные заголовки глав
- [ ] Библиотека: главы одной веб-новеллы собираются в одну группу-«книгу» (одна плитка на новеллу, внутри — список глав,
      прогресс и «продолжить» по последней прочитанной главе)
- [x] Виджет рабочего стола: починить (не работает). Причина: `<View>` в `widget_player.xml` запрещён в RemoteViews
      («Can't load widget»); заменён на `FrameLayout`, добавлен `previewLayout`
- [ ] Обновление: приложение само скачивает APK (прогресс, докачка, проверка размера) и запускает системную установку,
      а не отдаёт ссылку в браузер. Сейчас `UpdateManager.install` вызывает `PlatformActions.openUrl`.
      Нужно: загрузчик на базе `ModelDownloader`, `FileProvider`, разрешение `REQUEST_INSTALL_PACKAGES`,
      запрос «Установка из этого источника» при первом запуске, `ACTION_VIEW` с `application/vnd.android.package-archive`.
      На iOS остаётся страница релиза.
