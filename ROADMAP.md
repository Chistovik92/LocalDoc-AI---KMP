Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,

## 1.7.6 — бережное скачивание страниц · план

Сайты блокируют при скачивании новелл: сейчас главы идут пачками по 3 параллельно с паузой 250 мс
(`NovelDownloader`), а `WebHttp` не ограничивает частоту запросов и не учитывает ответы 429 / `Retry-After`.

- [ ] Ограничитель частоты в `WebHttp` — своя очередь на каждый хост: не более одного запроса за раз и
      минимальный интервал между ними (по умолчанию ~1–2 с), общий для скачивания глав, картинок и входа
- [ ] Случайный разброс интервала (jitter ±30 %), чтобы запросы не шли «по метроному»
- [ ] Обработка HTTP 429 / 503: чтение `Retry-After`, экспоненциальная пауза, автоматическое снижение скорости
      для хоста; после нескольких отказов подряд — остановка с понятным сообщением вместо бесконечных повторов
- [ ] Скачивание глав по одной (вместо пачек по 3), параллелизм только между разными хостами
- [ ] Картинки (`RemoteImages`, `ImageLoader`) — те же лимиты на хост, меньше параллельных загрузок
- [ ] Настройка в приложении: «Скорость скачивания» (осторожно / обычно / быстро) и пауза между главами
- [ ] Учёт `robots.txt` (`Crawl-delay`) там, где он задан
- [ ] Тесты: интервал между запросами к одному хосту, `Retry-After`, независимость хостов (фейковый `HttpTransport`)

## Размышления и предложения (после 1.7.5)

Идеи без версий; оценка: польза / сложность / риск. Берутся в план по мере спроса.

| Идея | Польза | Сложность | Риски и замечания |
| --- | --- | --- | --- |
| Синхронизация между устройствами (прогресс, закладки, подборки) через iCloud / Google Drive / WebDAV | высокая | средняя | конфликты правок; шифровать до отправки; не отправлять пароли сайтов |
| Постраничный рендер PDF с картинками и обложка PDF | высокая | средняя | Android `PdfRenderer`, iOS PDFKit; память — рендерить по странице с кэшем |
| ONNX-эмбеддинги (multilingual-e5-small) вместо хеширования | средняя | средняя | размер модели ~120 МБ, скорость на слабых телефонах; точка расширения `EmbeddingProvider` готова |
| Каталоги OPDS и офлайн-библиотеки (Flibusta-зеркала, Calibre-сервер, Project Gutenberg) | высокая | средняя | юридическая чистота источников; только открытые каталоги и свои серверы |
| Словари и цитаты: выделение текста, заметки, экспорт аннотаций (Markdown / EPUB) | высокая | средняя | хранение привязки к позиции при смене разбивки на страницы |
| Голосовое управление чтением («дальше», «назад», «пауза») | средняя | высокая | офлайн-распознавание речи (Vosk / Whisper), расход батареи |
| iOS-виджет с управлением плеером (App Intents) | средняя | средняя | только iOS 17+; ограничения фоновой работы |
| Доступность: TalkBack / VoiceOver, динамический шрифт, высокий контраст, управление с клавиатуры | высокая | средняя | аудит каждого экрана; подписи у картинок из `alt` |
| Локализация интерфейса (en, uk, de, es…) и словари строк | высокая | средняя | сейчас все строки в коде на русском — вынести в ресурсы |
| Автообновление скачанных новелл: проверка новых глав по расписанию, уведомления | высокая | средняя | фоновые задачи Android / iOS, бережное отношение к сайтам (интервалы, `robots.txt`) |
| Полнотекстовый поиск по библиотеке и каталогу | средняя | средняя | индекс на диске; для больших библиотек — инкрементальный |
| Mobi / AZW3 / CBZ (комиксы) / DJVU | средняя | высокая | Mobi проще (PalmDoc), DJVU требует декодера |
| Резервная копия библиотеки и настроек в файл (без паролей) | средняя | низкая | формат архива, версионирование |
| Совместное чтение и озвучка на втором устройстве (Cast / AirPlay) | низкая | высокая | сетевые протоколы платформ |
