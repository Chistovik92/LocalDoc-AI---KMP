# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 1.9.0; ближайшая — 2.0.0.

Дорожная карта: **2.0.0**. Версии 1.10–1.13, прежний 2.0.0 и все идеи без версий собраны в один большой
релиз 2.0.0: формат данных фиксируется один раз, после всех изменений хранилища и резервной копии.

## 2.0.0 — стабильный мажорный релиз · план

Одним релизом выходит всё, что раньше было разнесено по 1.10–1.13, прежнему 2.0.0 и «идеям без версий».
Работа идёт независимыми потоками (A–G), каждый — отдельной веткой и PR в ветку `release/2.0.0`; потоки E и F
выполняются последними, потому что затрагивают все экраны. Ограничение: то, что нельзя проверить на устройстве
или в iOS без macOS, проверяется тестами и CI; такие места отмечены в описании PR.

### A. Форматы и типографика

- [x] Постраничный рендер PDF с картинками (Android `PdfRenderer`, iOS PDFKit), кэш страниц ограниченного размера,
      рендер по одной странице ради памяти; режим «текст» (reflow) остаётся как альтернатива
- [x] Обложка PDF — первая страница
- [x] Mobi / AZW3 (начиная с PalmDoc), затем CBZ (комиксы) — Mobi 6 и AZW3 без DRM со сжатием PalmDOC; HUFF/CDIC и DRM — с понятным сообщением
- [ ] DJVU — остаётся вне плана: единственный зрелый декодер DjVuLibre распространяется под GPL, что несовместимо с MIT-лицензией проекта; свой декодер (JB2/IW44) — отдельный большой проект
- [x] Типографика читалки: свои шрифты из файлов (TTF/OTF) вместо двух семейств, поля страницы, межбуквенный интервал,
      жирность шрифта, растяжение пробелов при выключке
- [x] Настройки отдельной книги (шрифт, размер, поля, тема) поверх общих, со сбросом к общим
- [x] Тесты на тестовых файлах каждого формата; проверка пределов памяти на больших PDF

### B. Каталоги и автообновление новелл

Опирается на очередь запросов `HostThrottle` (пауза 10 с и отдых через случайное число запросов выпущены в 1.9.0).

- [x] OPDS-каталоги: поиск, навигация, скачивание; свои серверы (Calibre) и открытые каталоги
      (Project Gutenberg и подобные) — только законные источники (платные, пробные и «взять на время» ссылки пропускаются;
      скачиваются EPUB, FB2, DOCX, ODT, RTF, Markdown и текст)
- [x] Автообновление скачанных новелл: проверка новых глав по расписанию (WorkManager / BGTaskScheduler),
      интервалы и `robots.txt`, уведомление о новых главах (не проверено на устройстве: фоновые задачи и уведомления)
- [x] Пользовательские расписания и «тихие часы», отключение на мобильном интернете
- [x] Настройка «Скорость скачивания» (осторожно / обычно / быстро); по умолчанию «осторожно» (прежние 10 с и отдых), быстрее 1,2 с не бывает
- [x] Учёт `robots.txt` (`Crawl-delay` удлиняет паузу всегда; `Disallow` запрещает только автоматическую проверку по расписанию)
- [x] Тесты: расписание, дедупликация глав, поведение при блокировке сайтом (429 / 503), разбор OPDS
- [ ] OPDS: каталоги с паролем (Basic / Digest), PDF и MOBI из каталога (ждут потока A)
- [ ] Автообновление: докачка новых глав в фоне (сейчас приложение только сообщает о них; докачка — повторное «Скачать»)

### C. Семантический поиск на ONNX

- [x] Эмбеддинги `multilingual-e5-small` (ONNX Runtime) вместо хеширования признаков через `EmbeddingProvider`
- [x] Скачивание модели по запросу (~120 МБ) с прогрессом и возможностью удалить; без неё работает прежний режим
- [x] Пересчёт индекса при смене провайдера, версия индекса в `VectorStore`
- [x] Порог отказа от модели: память ≥ 2800 МБ и замер скорости при запуске (> 1,5 с на фрагмент — отказ)
- [ ] Замеры скорости и памяти на реальных слабых телефонах (подобрать пороги по данным)
- [ ] ONNX Runtime на iOS (сейчас там работает хеширование)

### D. Данные: синхронизация, копии, миграции

- [x] Синхронизация прогресса, закладок, аннотаций и подборок через WebDAV (общий код, тесты на подставном облаке)
- [ ] Транспорты iCloud и Google Drive: интерфейс `SyncTransport` и заготовки `expect/actual` готовы, реализации
      требуют проверки на устройстве (контейнер iCloud и entitlement, OAuth-клиент Google)
- [x] Шифрование на устройстве до отправки (PBKDF2-HMAC-SHA256 + AES-256-GCM, cryptography-kotlin); пароли сайтов не синхронизируются
- [x] Разрешение конфликтов (последняя правка по каждой записи, журнал изменений), безопасный режим при расхождении
- [x] Миграции хранилища: чистый апгрейд с любой 1.x, тесты на данных предыдущих версий
- [x] Замороженный формат резервной копии и синхронизации (`docs/BACKUP_FORMAT.md`, версия 2); сжатие копии (Deflate при записи)
- [x] Копия по расписанию (при запуске приложения); фоновый планировщик WorkManager / BGTaskScheduler — отдельным шагом
- [x] Тесты: конфликты, частичная синхронизация, обрыв связи

### E. Новые возможности

- [x] iOS-виджет с управлением плеером (App Intents, iOS 17+: назад / пауза / вперёд); не проверено без macOS и устройства,
      состояние плеера в виджете не показывается (нужна App Group)
- [x] Статистика чтения (время, скорость, серия и столбики по дням): хранится локально, паузы и простой не засчитываются,
      экран в «Настройках», входит в резервную копию необязательным ключом (формат версии 1 не менялся)
- [x] Таймер сна для озвучки (через 15–90 минут или до конца главы), плавное затухание, фоновый сервис останавливается
- [x] Голосовое управление чтением («дальше», «назад», «пауза», «продолжай»): офлайн-распознавание системными средствами
      (Android 13+, iOS с загруженной моделью), выключено по умолчанию, слушает только при открытом плеере
- [~] Озвучка и чтение на втором устройстве: кнопка системного выбора вывода звука (AirPlay на iOS, панель вывода Android);
      собственная передача на Chromecast невозможна без своего сетевого протокола и в план не входит

### F. Доступность и локализация

Выполняется после A–E: затрагивает все экраны.

- [x] Все строки интерфейса из кода в ресурсы (`ui/**`), словари `ru`, `en`, `uk`, `de`, `es`; тексты служебных слоёв
      (статусы сканирования и скачивания, описания моделей, запросы к ИИ) остались на русском — отдельным шагом
- [x] Выбор языка интерфейса независимо от системного (Android — сразу, iOS — после перезапуска); запятая/точка в дробях по языку
- [~] TalkBack / VoiceOver: роли, подписи, заголовки, `stateDescription` переключателей, подписи картинок из `alt`;
      не проверено со скринридером на устройстве (`docs/ACCESSIBILITY.md`)
- [x] Динамический размер шрифта системы, высококонтрастная тема, уважение «уменьшить анимацию» (система и настройка)
- [~] Управление с клавиатуры: листание, оглавление, закладка, пауза озвучки; поиска по тексту внутри книги в читалке
      нет, горячей клавиши для него тоже
- [x] Аудит экранов по чек-листу (`docs/ACCESSIBILITY.md`), автоматическая проверка литералов и полноты словарей

### H. Постраничное чтение по размеру экрана

Страница — столько текста, сколько помещается на экран при выбранных шрифте, размере, интервале, полях и выключке
(как в читалках вроде CoolReader; по поведению, код не заимствуется — лицензии несовместимы).

- [x] Чистая вёрстка `ScreenPager` (commonMain, тесты): абзац делится по строкам, без одиночных строк на краях,
      заголовок не последний, глава с новой страницы, картинка своей высоты; места — «блок + смещение»
- [x] Измеритель на Compose `TextMeasurer` с теми же стилями, что при отрисовке (общая типографика `ReaderTypography`)
- [x] Отрисовка страницы срезами блоков, листание зонами, свайпом, кнопками громкости; озвучка переворачивает страницу сама
- [x] Расчёт в фоне при смене размера, шрифта, интервала, полей, выключки, поворота; кэш по ключу; место переживает пересчёт
- [x] «N из M» экранными страницами (M уточняется), ползунок по страницам; «Порция для озвучки и перевода» — прежний `BookPager`
- [ ] Проверка на устройстве: совпадение высоты страниц с отрисовкой, плавность, e-ink, iOS
