## 1.6.5 — улучшение UI и виджет

- [x] UI: исправить «расползающиеся» кнопки (проверка всех экранов на эмуляторе, узкие ширины, крупный шрифт)
- [x] UI (со скриншотов пользователя): кнопка «Слушать» в карточке «Продолжить чтение» сжимается в круг с вертикальным
      текстом; плавающая «Добавить» перекрывает плитки книг; обрезанные заголовки глав
- [x] Библиотека: главы одной веб-новеллы собираются в одну группу-«книгу» (одна плитка на новеллу, внутри — список глав,
      прогресс и «продолжить» по последней прочитанной главе)
- [x] Виджет рабочего стола: починить (не работает). Причина: `<View>` в `widget_player.xml` запрещён в RemoteViews
      («Can't load widget»); заменён на `FrameLayout`, добавлен `previewLayout`
- [x] Обновление: приложение само скачивает APK (прогресс, отмена, докачка) и запускает системную установку,
      а не отдаёт ссылку в браузер: `UpdateManager` на базе `ModelDownloader`, `FileProvider`, разрешение
      `REQUEST_INSTALL_PACKAGES` и запрос «Установка из этого источника». На iOS остаётся страница релиза.
