# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 1.7.0.

## 1.7.5 — в разработке

Качество, вход на сайтах, скачивание и конвертация книг, форматы, обложки и картинки.

**A. Качество** (в таком порядке)

- [ ] 1) Поиск ошибок в коде
- [ ] 2) Аудит устойчивости: падения, утечки, гонки, обработка ошибок и повреждённых файлов, большие файлы, отмена,
      повороты экрана, нехватка памяти/сети
- [ ] 3) Повторная проверка всего UI на эмуляторе: все экраны, светлая/тёмная тема, шрифт ×1.3, узкая ширина;
      текст в кнопках `maxLines=1`/`softWrap=false`, группы кнопок — `FlowRow`; виджет — без `View`/`Space` в RemoteViews

**B. Вход на сайтах**

- [ ] Ввод логина/пароля на ресурсах с веб-новеллами, рассказами, книгами, если он нужен для доступа;
      сохранение сессии (cookies) и самих данных
- [ ] Безопасность: пароли только в защищённом хранилище платформы (`expect/actual`: Android Keystore /
      EncryptedSharedPreferences, iOS Keychain); никогда в логах, URL, обычных prefs и резервных копиях;
      cookies сессии шифруются; кнопка «Выйти / Забыть сайт» удаляет всё одним нажатием
- [ ] Только легитимный вход: не обходить капчу, paywall и защиту; если нужна капча — открыть страницу входа
      в системном WebView/браузере и забрать сессию

**C. Веб-новеллы: автопереход «Далее»**

- [ ] Опция «автоматически нажимать «Далее» и продолжать читать»: ссылку следующей главы находит нейросеть
      (локальная модель), если маркеров нет (частично есть в `WebSession`); работает вместе с озвучкой

**D. Скачивание всей книги**

- [ ] Скачать произведение целиком: EPUB и/или FB2 / FB2.ZIP / TXT / RTF / XML или другой поддерживаемый формат
- [ ] Отдельная папка для скачанных страниц веб-новеллы/фанфика, с которых читает приложение, — для склейки
      в единую книгу (главы, оглавление)
- [ ] Если сайт отдаёт книгу целиком (API, ссылка «скачать» на странице описания, оглавления или каждой страницы) —
      скачивать штатно, а не собирать по страницам; такие ссылки находятся автоматически
- [ ] Пункт «Скачать» в меню вкладки «Книги» (долгий тап на книгу) и в меню каждой страницы в читалке
- [ ] Прогресс, отмена, докачка (как у `ModelDownloader`), понятные ошибки

**E. Форматы** (добавить, если нет): docx, doc, docm, dotx, dotm, pdf, odt, rtf, txt, htm, html, xml, wps, pages

- [ ] Определение по расширению и по сигнатуре (OLE2 `D0CF11E0`, ZIP, `%PDF` и т. п.); бинарные файлы
      не принимать за текст
- [ ] Для каждого формата — парсер в общую модель `Book` + тесты; неразбираемый формат — понятная ошибка, без падения

**F. Конвертация форматов** (импорт → `Book` → экспорт)

- [ ] Минимум: EPUB, FB2(.zip), DOCX, ODT, RTF, TXT, HTML, Markdown, XML; сохраняются заголовки, списки,
      выделения, главы, оглавление, обложка, картинки
- [ ] Тесты на круговые преобразования
- [ ] «Сохранить как…» в меню книги

**G. Обложки и картинки**

- [ ] Обложки из EPUB/FB2/DOCX/ODT/первой страницы PDF/страницы веб-новеллы — в читалке, библиотеке, экспорте
- [ ] Картинки в тексте (EPUB, FB2, DOCX, ODT, HTML, веб-страницы)
- [ ] Кэш на диск, ограничение размера, ленивая загрузка, без OOM

**H. Документация**

- [ ] README.md (возможности, форматы, сборка), CHANGELOG.md (раздел 1.7.5 + строка в «Сводке версий»),
      `.github/release-notes.md`; после релиза раздел 1.7.5 отсюда удаляется

**J. Сканирование устройства и подборки книг**

- [ ] Сканирование файлов книг: всё устройство, выбранная папка и/или подключённый ресурс (SD-карта, USB, сетевая/облачная
      папка через системный выбор папки); фоновый обход с прогрессом и отменой, повторное сканирование находит только новое
- [ ] Метаданные для каталога без полного разбора: название, автор, жанр, год, язык, серия, обложка
      (EPUB/FB2/DOCX/ODT/PDF — из заголовка файла; иначе из имени файла)
- [ ] Подборки по образцу полок интернет-магазинов: «Недавно добавленные», «Продолжить», «Авторы», «Жанры», «Годы»,
      «Серии», «Языки», «Форматы», «Папки»; фильтры и сортировка (автор / жанр / год / название / дата / размер),
      свои подборки пользователя
- [ ] Найденные файлы можно просматривать в каталоге, не добавляя в библиотеку, и добавлять по одному или подборкой
