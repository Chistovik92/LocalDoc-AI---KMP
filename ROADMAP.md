# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 1.8.0; ближайшая — 1.9.0.

Дорожная карта: 1.9.0 → 1.10.0 → 1.11.0 → 1.12.0 → 1.13.0 → **2.0.0**.
Порядок выбран так, чтобы каждая версия опиралась на предыдущую: сначала
данные пользователя (аннотации, копии), доступность и локализация, форматы, каталоги, ИИ и в конце синхронизация.

## 1.9.0 — доступность и локализация · план

- [ ] Все строки интерфейса из кода в ресурсы (сейчас русские литералы), словари `ru` и `en`; затем `uk`, `de`, `es`
- [ ] Выбор языка интерфейса независимо от системного; форматы дат и чисел по локали
- [ ] TalkBack / VoiceOver: подписи элементов, порядок фокуса, роли; подписи картинок из `alt`
- [ ] Динамический размер шрифта системы, высококонтрастная тема, уважение «уменьшить анимацию»
- [ ] Управление с клавиатуры (планшеты, Bluetooth-клавиатуры): фокус, горячие клавиши читалки
- [ ] Аудит каждого экрана по чек-листу, автоматическая проверка отсутствия строк-литералов в UI
- [ ] Цитаты: нажатие на подсвеченное место в тексте открывает заметку; выбор цвета подсветки (не вошло в 1.8.0)
- [x] Умное оглавление: поиск начал глав прямо в тексте по словам «Глава», «Часть», «Пролог», «Эпилог», «Предисловие»,
      «Интерлюдия», Chapter, Part и т. п. (с номерами цифрами, словами и римскими) — список слов настраивается;
      ручная отметка «здесь начало главы» в панели выделения текста
- [x] Разбиение на главы нейросетью, когда явных заголовков нет: локальная модель выбирает границы и придумывает названия;
      предпросмотр с правкой названий и границ до применения; работает окнами, чтобы хватало слабого телефона
- [x] Сохранение оглавления: в библиотеку (без потери закладок и цитат) и в файл — «пересохранить» скачанную книгу
      без оглавления в EPUB / FB2 уже с оглавлением
- [ ] Словарь: кнопки «Найти в интернете» и «Википедия» рядом с переводом слова
- [ ] Управление читалкой: настраиваемые зоны касания (листание краями, меню в центре), листание кнопками громкости,
      щипок для размера шрифта, свайп для листания; яркость жестом, «не гасить экран», блокировка ориентации
- [ ] Анимация листания (выключается вместе с «уменьшить анимацию») и автопрокрутка со скоростью
- [ ] Режим для e-ink: без анимаций, полное обновление экрана раз в N страниц

## 1.10.0 — PDF и новые форматы · план

- [ ] Постраничный рендер PDF с картинками (Android `PdfRenderer`, iOS PDFKit), кэш страниц ограниченного размера,
      рендер по одной странице ради памяти; режим «текст» (reflow) остаётся как альтернатива
- [ ] Обложка PDF — первая страница
- [ ] Mobi / AZW3 (начиная с PalmDoc), затем CBZ (комиксы)
- [ ] DJVU — только если найдётся приемлемый по лицензии и размеру декодер, иначе остаётся вне плана
- [ ] Тесты на тестовых файлах каждого формата; проверка пределов памяти на больших PDF
- [ ] Типографика читалки: свои шрифты из файлов (TTF/OTF) вместо двух семейств, поля страницы, межбуквенный интервал,
      жирность шрифта, растяжение пробелов при выключке
- [ ] Настройки отдельной книги (шрифт, размер, поля, тема) поверх общих, со сбросом к общим

## После 2.0.0 (идеи без версий)

Оценка: польза / сложность / риск. Берутся в план по мере спроса.

| Идея | Польза | Сложность | Риски и замечания |
| --- | --- | --- | --- |
| Статистика чтения (время, скорость, прогресс по дням) | средняя | низкая | хранить локально; учитывать паузы, чтобы не завышать время |
| Таймер сна для озвучки (остановка через N минут или в конце главы) | средняя | низкая | плавное затухание, корректная остановка фонового сервиса |
| Голосовое управление чтением («дальше», «назад», «пауза») | средняя | высокая | офлайн-распознавание речи (Vosk / Whisper), расход батареи |
