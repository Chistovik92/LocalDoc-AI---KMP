# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 2.9.0.

Дорожная карта: 2.10.0, затем большие проекты **3.0.0** и **4.0.0**.
Версии 2.x — проверка на устройствах, доводка и то, что требует аккаунтов; два больших проекта, которые не помещаются
в минорные версии, вынесены в 3.0.0 и 4.0.0.

## 2.4.0 — сеть, перевод, устойчивость · выпущена (v2.4.3)

Завершено: DNS-перепривязка и cleartext-политика, потоковая озвучка перевода, Google Translate, вход на сайтах,
тема оформления — см. [CHANGELOG.md](CHANGELOG.md). Четыре недоделанных пункта (импорт, Native, PDF, системный TTS)
вышли в 2.5.5.

## 2.5.0 — производительность и пороги · выпущена (v2.5.0)

Кольцевое логирование, общий словарь слов для поиска по тысячам книг, отложенная запись прогресса чтения —
см. [CHANGELOG.md](CHANGELOG.md). Единственный недоделанный пункт («Замеры скорости и памяти умного поиска…»)
перенесён в 2.7.0.

## 2.5.5 — Native, импорт, PDF и системный TTS · выпущена (v2.5.5)

Готовое из 2.6.0 вышло отдельным релизом, не дожидаясь разблокировки M3 Expressive:

- [x] Импорт: суммарный лимит распаковки и PDF-копирования, отмена на всех этапах; OOM не считается исправленным перехватом `Throwable`
- [x] Native: проверены выделения sampler и границы C ABI на исключения, гонки generate/abort/free; ASan/UBSan и сборка с закреплённым llama.h b10004
- [x] PDF: открываются как в обычной читалке (быстрый просмотр), OCR-вариант — по выбору уже после открытия
- [x] Озвучка без нейросети: системный TTS-движок читает текст сам (меньше нагрузки) — используется, когда доступен

Устройственная приёмка этих пунктов — отдельной вехой 2.8.0.

## 2.6.0 — M3 Expressive во всей программе · выпущена (v2.6.0)

- [x] M3 Expressive во всей программе: `MaterialExpressiveTheme` + `MotionScheme.expressive()` на всю программу;
      принята alpha-обёртка `org.jetbrains.compose.material3:material3:1.13.0-beta02` (API публичны)
- [x] Меню «⋮» читалки и веба переработано: три секции с иконками и разделителями, переключатели с галочками
- [x] Исправлено: текст периодически выезжал за границы страницы — padding шрифта резервируется на каждой странице
      разрезанного абзаца

Итог — в [CHANGELOG.md](CHANGELOG.md).

## 2.10.0 — приёмка на устройствах и витрина · план

- [ ] Замеры скорости и памяти умного поиска на реальных слабых телефонах (полный RAG с ONNX e5);
      по данным уточнить пороги `SemanticModelPolicy`. Инфраструктура (script, benchmark, CI) готова,
      но физические замеры ещё не проводились.
- [ ] Реальная проверка OAuth Google Drive и iCloud: вход, синхронизация, обрыв связи и конфликт версий.
- [ ] Проверка на устройстве с установленными LocalDoc AI и NeuroCode: список моделей и импорт копированием.
- [ ] Обновлённые скриншоты в README (делаются вручную на устройствах).

## 3.0.0 — собственный декодер DJVU · большой проект

Единственный зрелый декодер DjVuLibre распространяется под GPL, что несовместимо с MIT-лицензией проекта, поэтому нужен собственный.

- [ ] Разбор контейнера DJVU (IFF, страницы, закладки) и текстового слоя
- [ ] Декодеры слоёв: JB2 (маска) и IW44 (фон и передний план); сборка страницы в изображение
- [ ] Постраничный просмотр с кэшем и ограничением памяти, как у PDF; текстовый слой для озвучки и поиска
- [ ] Тестовые файлы всех видов, проверка пределов памяти и скорости на слабых устройствах; чистая лицензия (без кода GPL)

## 4.0.0 — чтение и озвучка на других устройствах · большой проект

Системный выбор вывода звука (AirPlay, панель вывода Android) уже есть; здесь — передача на Chromecast и другие устройства.

- [ ] Исследование: Cast без проприетарного SDK (протокол, обнаружение по mDNS), совместимость лицензий, оценка трудоёмкости
- [ ] Передача озвучки на устройство Cast и управление с телефона (пауза, перемотка по предложениям)
- [ ] Показ страницы чтения на втором экране (по возможности платформ)

## 4.5.0 — генерация аудиокниг · большой проект

Экспорт озвучки в готовый аудиофайл: из вебновеллы (все страницы скачиваются с любой доступной
площадки — OPDS, прямые сайты, каталоги) или любой электронной книги, с сохранением разбивки по главам.

- [ ] Полное скачивание вебновеллы: обход всех страниц/глав с площадки (учитывать существующие парсеры и каталоги), сборка единой книги
- [ ] Конвертация электронной книги в исходник для синтеза с сохранением формата по главам (оглавление → главы аудиокниги)
- [ ] Оффлайн-синтез всей книги по главам (движки озвучки 2.x): очередь, докачка после обрыва, отмена, прогресс
- [ ] Кодирование в аудиоформаты по выбору: MP3, WAV, MP4 (AAC), OGG (и другие по возможности);	expect/actual для платформенных энкодеров
- [ ] Сохранение по главам: отдельные файлы глав + обложка/метаданные (глава как трек, порядок, названия);	m4b-контейнер (аудиокнига с главами) — по возможности
- [ ] Фоновая генерация без блокировки UI, продолжение после перезапуска приложения
- [ ] Тесты: конвейер «страницы → главы → аудио» на подставных движках, пределы памяти на больших книгах
- [ ] Тесты на подставном приёмнике, проверка на реальных устройствах
