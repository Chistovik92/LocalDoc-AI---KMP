# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 2.3.0.

Дорожная карта: 2.4.0 → 2.5.0 → … → 2.8.0, затем большие проекты **3.0.0** и **4.0.0**.
Версии 2.x — проверка на устройствах, доводка и то, что требует аккаунтов; два больших проекта, которые не помещаются
в минорные версии, вынесены в 3.0.0 и 4.0.0.

## 2.4.0 — сеть, перевод, устойчивость и M3 Expressive · в разработке

- [x] Защита от DNS-перепривязки (проверка IP соединения в `RawHttp`, обе платформы) и размер файла до `readBytes` (большой файл не грузится в память)
- [x] Открытый `http://` для OPDS/WebDAV домашней сети: `network_security_config` + согласие в настройках каталогов; публичные сайты по http не открываются никогда (`NetSafety.checkCleartext`)
- [x] Сэмпл голоса: повторный тап отменяет звучащий и ожидающие запросы, `release` гасит очередь (`VoiceSamplePlayer`, эпохи)
- [x] Озвучка перевода по мере готовности: `StreamingPageTranslation` ждёт только первый блок (20 с), готовые блоки звучат переводом, остальные — оригиналом; текст не теряется
- [x] Перевод веб-страниц через Google Translate (открытый эндпоинт `translate_a/single`, без ключа) — тот же сервис, что «встроенный переводчик» сайтов (ranobes и т. п.); настройка «брать перевод со страницы» теперь имеет поведение
- [x] Поля входа и регистрации на сайте в настройках («Сайты и вход»), пока открыта сессия на сайте
- [x] Авторизация: POST только по https на тот же origin, пароли не уходят на http/чужой домен/GET, cookie из браузера копируются только на родственные хосты
- [x] Сеть: тесты origin/портов/URL с userinfo, DNS-перепривязка (публичное имя → внутренний адрес) и приватные IPv4/IPv6 на общем коде
- [ ] M3 Expressive во всей программе: **заблокировано зависимостью** — `MaterialExpressiveTheme`/`MotionScheme.expressive()` существуют в резолвящейся обёртке `org.jetbrains.compose.material3:material3:1.9.0`, но помечены internal; публичны они только в 1.10+ (alpha). Ждём stable-обёртку или принимаем alpha — решение в следующей версии
- [ ] Импорт: суммарный лимит распаковки и PDF-копирования, отмена на всех этапах; OOM нельзя считать исправленным перехватом Throwable
- [ ] Native: проверить выделения sampler и границы C ABI на исключения, гонки generate/abort/free; ASan/UBSan и сборка с закреплённым llama.h b10004
- [ ] Приёмка: зелёный unit suite не доказывает готовность потоковой озвучки и UI — device-тесты Android + iOS CI

## 3.0.0 — собственный декодер DJVU · большой проект

Единственный зрелый декодер DjVuLibre распространяется под GPL, что несовместимо с MIT-лицензией проекта, поэтому нужен собственный.

- [ ] Разбор контейнера DJVU (IFF, страницы, закладки) и текстового слоя
- [ ] Декодеры слоёв: JB2 (маска) и IW44 (фон и передний план); сборка страницы в изображение
- [ ] Постраничный просмотр с кэшем и ограничением памяти, как у PDF; текстовый слой для озвучки и поиска
- [ ] Тестовые файлы всех видов, проверка пределов памяти и скорости на слабых устройствах; чистая лицензия (без кода GPL)

## 4.5.0 — генерация аудиокниг · большой проект

Экспорт озвучки в готовый аудиофайл: из вебновеллы (все страницы скачиваются с любой доступной
площадки — OPDS, прямые сайты, каталоги) или любой электронной книги, с сохранением разбивки по главам.

- [ ] Полное скачивание вебновеллы: обход всех страниц/глав с площадки (учитывать существующие парсеры и каталоги), сборка единой книги
- [ ] Конвертация электронной книги в исходник для синтеза с сохранением формата по главам (оглавление → главы аудиокниги)
- [ ] Оффлайн-синтез всей книги по главам (движки озвучки 2.x): очередь, докачка после обрыва, отмена, прогресс
- [ ] Кодирование в аудиоформаты по выбору: MP3, WAV, MP4 (AAC), OGG (и другие по возможности);	expect/actual для платформенных энкодеров
- [ ] Сохранение по главам: отдельные файлы глав + обложка/метаданные (глава как трек, порядок, названия);	m4b-контейнер (аудиокнига с главами) — по возможности
- [ ] Фоновая генерация без блокировки UI, продолжение после перезапуска приложения
- [ ] Тесты: конвейер «страницы → главы → аудио» на подставных движках, пределы памяти на больших книгах
- [ ] Тесты на подставном приёмнике, проверка на реальных устройствах
