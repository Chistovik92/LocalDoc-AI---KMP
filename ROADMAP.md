# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 1.7.6; ближайшая — 1.8.0.

Дорожная карта: 1.8.0 → 1.9.0 → 1.10.0 → 1.11.0 → 1.12.0 → 1.13.0 → **2.0.0**.
Порядок выбран так, чтобы каждая версия опиралась на предыдущую: сначала
данные пользователя (аннотации, копии), доступность и локализация, форматы, каталоги, ИИ и в конце синхронизация.

Данные пользователя: то, что нельзя потерять и что нужно находить.

- [ ] Тесты: переживание смены шрифта / разбивки у закладок и цитат, round-trip резервной копии

## 1.9.0 — доступность и локализация · план

- [ ] Все строки интерфейса из кода в ресурсы (сейчас русские литералы), словари `ru` и `en`; затем `uk`, `de`, `es`
- [ ] Выбор языка интерфейса независимо от системного; форматы дат и чисел по локали
- [ ] TalkBack / VoiceOver: подписи элементов, порядок фокуса, роли; подписи картинок из `alt`
- [ ] Динамический размер шрифта системы, высококонтрастная тема, уважение «уменьшить анимацию»
- [ ] Управление с клавиатуры (планшеты, Bluetooth-клавиатуры): фокус, горячие клавиши читалки
- [ ] Аудит каждого экрана по чек-листу, автоматическая проверка отсутствия строк-литералов в UI

## 1.10.0 — PDF и новые форматы · план

- [ ] Постраничный рендер PDF с картинками (Android `PdfRenderer`, iOS PDFKit), кэш страниц ограниченного размера,
      рендер по одной странице ради памяти; режим «текст» (reflow) остаётся как альтернатива
- [ ] Обложка PDF — первая страница
- [ ] Mobi / AZW3 (начиная с PalmDoc), затем CBZ (комиксы)
- [ ] DJVU — только если найдётся приемлемый по лицензии и размеру декодер, иначе остаётся вне плана
- [ ] Тесты на тестовых файлах каждого формата; проверка пределов памяти на больших PDF

## 1.11.0 — каталоги и автообновление новелл · план

Опирается на очередь запросов `HostThrottle` (выпущена в 1.7.6).

- [ ] OPDS-каталоги: поиск, навигация, скачивание; свои серверы (Calibre) и открытые каталоги
      (Project Gutenberg и подобные) — только законные источники
- [ ] Автообновление скачанных новелл: проверка новых глав по расписанию (WorkManager / BGTaskScheduler),
      интервалы и `robots.txt`, уведомление о новых главах
- [ ] Пользовательские расписания и «тихие часы», отключение на мобильном интернете
- [ ] Настройка «Скорость скачивания» (осторожно / обычно / быстро) и пауза между главами; сейчас пауза зашита в `HostThrottle`
- [ ] Учёт `robots.txt` (`Crawl-delay`) там, где он задан
- [ ] Тесты: расписание, дедупликация глав, поведение при блокировке сайтом

## 1.12.0 — семантический поиск на ONNX · план

## 1.13.0 — синхронизация между устройствами · план

## 2.0.0 — стабильный мажорный релиз · план

Цель — зафиксировать форматы данных и довести качество; новых больших возможностей минимум.

- [ ] iOS-виджет с управлением плеером (App Intents, iOS 17+); сейчас виджет только открывает приложение по ссылке
- [ ] Миграции хранилища: чистый апгрейд с любой 1.x, тесты на данных предыдущих версий
- [ ] Замороженный формат резервной копии и синхронизации (документирован, с версией)
- [ ] Аудит производительности и памяти, холодный старт, большие библиотеки
- [ ] Аудит безопасности: хранение секретов, сеть, разбор чужих файлов
- [ ] Полный проход по доступности и локализации, обновлённые скриншоты и README
