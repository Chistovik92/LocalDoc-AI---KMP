# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 1.8.0; ближайшая — 1.9.0.

Дорожная карта: 1.9.0 → **2.0.0**. Версии 1.10–1.13, прежний 2.0.0 и все идеи без версий собраны в один большой
релиз 2.0.0: формат данных фиксируется один раз, после всех изменений хранилища и резервной копии.

## 1.9.0 — удобная читалка · в разработке

Умное оглавление выпускается в этой версии (пункты со ✓ ниже). Доступность и локализация перенесены в 2.0.0,
потому что затрагивают каждый экран и делаются после всех остальных изменений интерфейса.

- [x] Умное оглавление: поиск начал глав прямо в тексте по словам «Глава», «Часть», «Пролог», «Эпилог», «Предисловие»,
      «Интерлюдия», Chapter, Part и т. п. (с номерами цифрами, словами и римскими) — список слов настраивается;
      ручная отметка «здесь начало главы» в панели выделения текста
- [x] Разбиение на главы нейросетью, когда явных заголовков нет: локальная модель выбирает границы и придумывает названия;
      предпросмотр с правкой названий и границ до применения; работает окнами, чтобы хватало слабого телефона
- [x] Сохранение оглавления: в библиотеку (без потери закладок и цитат) и в файл — «пересохранить» скачанную книгу
      без оглавления в EPUB / FB2 уже с оглавлением
- [x] Цитаты: нажатие на подсвеченное место в тексте открывает заметку; выбор цвета подсветки (не вошло в 1.8.0)
- [x] Словарь: кнопки «Найти в интернете» и «Википедия» рядом с переводом слова
- [x] Управление читалкой: настраиваемые зоны касания (листание краями, меню в центре), листание кнопками громкости,
      щипок для размера шрифта, свайп для листания; яркость жестом, «не гасить экран», блокировка ориентации
      (на iOS нет кнопок громкости и блокировки ориентации — у системы нет для них открытого API)
- [x] Анимация листания (выключается вместе с «уменьшить анимацию») и автопрокрутка со скоростью
- [x] Режим для e-ink: без анимаций, полное обновление экрана раз в N страниц

## 2.0.0 — стабильный мажорный релиз · план

Одним релизом выходит всё, что раньше было разнесено по 1.10–1.13, прежнему 2.0.0 и «идеям без версий».
Работа идёт независимыми потоками (A–G), каждый — отдельной веткой и PR в ветку `release/2.0.0`; потоки E и F
выполняются последними, потому что затрагивают все экраны. Ограничение: то, что нельзя проверить на устройстве
или в iOS без macOS, проверяется тестами и CI; такие места отмечены в описании PR.

### A. Форматы и типографика

- [x] Постраничный рендер PDF с картинками (Android `PdfRenderer`, iOS PDFKit), кэш страниц ограниченного размера,
      рендер по одной странице ради памяти; режим «текст» (reflow) остаётся как альтернатива
- [x] Обложка PDF — первая страница
- [x] Mobi / AZW3 (начиная с PalmDoc), затем CBZ (комиксы) — Mobi 6 и AZW3 без DRM со сжатием PalmDOC; HUFF/CDIC и DRM — с понятным сообщением
- [ ] DJVU — остаётся вне плана: единственный зрелый декодер DjVuLibre распространяется под GPL, что несовместимо с MIT-лицензией проекта; свой декодер (JB2/IW44) — отдельный большой проект
- [x] Типографика читалки: свои шрифты из файлов (TTF/OTF) вместо двух семейств, поля страницы, межбуквенный интервал,
      жирность шрифта, растяжение пробелов при выключке
- [x] Настройки отдельной книги (шрифт, размер, поля, тема) поверх общих, со сбросом к общим
- [x] Тесты на тестовых файлах каждого формата; проверка пределов памяти на больших PDF

### B. Каталоги и автообновление новелл

Опирается на очередь запросов `HostThrottle` (пауза 10 с и отдых через случайное число запросов выпущены в 1.9.0).

- [ ] OPDS-каталоги: поиск, навигация, скачивание; свои серверы (Calibre) и открытые каталоги
      (Project Gutenberg и подобные) — только законные источники
- [ ] Автообновление скачанных новелл: проверка новых глав по расписанию (WorkManager / BGTaskScheduler),
      интервалы и `robots.txt`, уведомление о новых главах
- [ ] Пользовательские расписания и «тихие часы», отключение на мобильном интернете
- [ ] Настройка «Скорость скачивания» (осторожно / обычно / быстро) и пауза между главами; сейчас пауза зашита в `HostThrottle`
- [ ] Учёт `robots.txt` (`Crawl-delay`) там, где он задан
- [ ] Тесты: расписание, дедупликация глав, поведение при блокировке сайтом

### C. Семантический поиск на ONNX

- [ ] Эмбеддинги `multilingual-e5-small` (ONNX Runtime) вместо хеширования признаков через `EmbeddingProvider`
- [ ] Скачивание модели по запросу (~120 МБ) с прогрессом и возможностью удалить; без неё работает прежний режим
- [ ] Пересчёт индекса при смене провайдера, версия индекса в `VectorStore`
- [ ] Замеры скорости и памяти на слабых телефонах, порог отказа от модели

### D. Данные: синхронизация, копии, миграции

- [ ] Синхронизация прогресса, закладок, аннотаций и подборок через iCloud / Google Drive / WebDAV
- [ ] Шифрование на устройстве до отправки; пароли сайтов не синхронизируются
- [ ] Разрешение конфликтов (последняя правка по каждой записи, журнал изменений), безопасный режим при расхождении
- [ ] Миграции хранилища: чистый апгрейд с любой 1.x, тесты на данных предыдущих версий
- [ ] Замороженный формат резервной копии и синхронизации (документирован, с версией); сжатие копии (Deflate при записи) и копия по расписанию
- [ ] Тесты: конфликты, частичная синхронизация, обрыв связи

### E. Новые возможности

- [ ] iOS-виджет с управлением плеером (App Intents, iOS 17+); сейчас виджет только открывает приложение по ссылке
- [ ] Статистика чтения (время, скорость, прогресс по дням): хранится локально, паузы не засчитываются
- [ ] Таймер сна для озвучки (остановка через N минут или в конце главы), плавное затухание, корректная остановка сервиса
- [ ] Голосовое управление чтением («дальше», «назад», «пауза»): офлайн-распознавание речи, отключаемое, с оценкой расхода батареи
- [ ] Озвучка и чтение на втором устройстве (Cast / AirPlay) в пределах возможностей платформ

### F. Доступность и локализация

Выполняется после A–E: затрагивает все экраны.

- [ ] Все строки интерфейса из кода в ресурсы (сейчас русские литералы), словари `ru` и `en`; затем `uk`, `de`, `es`
