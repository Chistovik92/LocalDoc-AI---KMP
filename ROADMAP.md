# План версий

Единственный источник **будущих** планов проекта. Выпущенное и исправленное записывается в
[CHANGELOG.md](CHANGELOG.md), правила разработки — в [AGENTS.md](AGENTS.md). Новый пункт попадает сюда сразу,
как только появился; при релизе раздел версии удаляется отсюда, а его итог остаётся только в CHANGELOG —
так история не дублируется.

Статусы версий: **в разработке** · **план**. Последняя выпущенная версия — 2.0.0; следующая версия пока не назначена.

## После 2.0.0 · план

Сюда перенесено то, что не вошло в 2.0.0: нельзя проверить без устройства, macOS или аккаунтов, либо найдено аудитами.

### Данные и сеть

- [ ] Транспорты iCloud и Google Drive для синхронизации: интерфейс `SyncTransport` и заготовки `expect/actual` готовы, реализации
      требуют проверки на устройстве (контейнер iCloud и entitlement, OAuth-клиент Google)
- [ ] OPDS: каталоги с паролем (Basic / Digest), PDF и MOBI из каталога
- [ ] Автообновление новелл: докачка новых глав в фоне (сейчас приложение только сообщает о них; докачка — повторное «Скачать»)
- [ ] Аудит: защита от DNS-перепривязки (проверка IP соединения в `RawHttp`) и потоковое чтение больших входных файлов вместо `readBytes`
- [ ] Аудит: `network_security_config` для каталогов OPDS и WebDAV по `http://` в домашней сети (сейчас системы блокируют открытый http)

### Поиск и производительность

- [ ] Замеры скорости и памяти умного поиска на реальных слабых телефонах (подобрать пороги по данным)
- [ ] ONNX Runtime на iOS (сейчас там работает хеширование)
- [ ] Аудит: поиск по тысячам книг без чтения шарда каждой книги с диска (общий словарь слов), отложенная запись прогресса чтения; нужны замеры на устройстве

### Читалка и доступность

- [ ] Постраничное чтение: проверка на устройстве — совпадение высоты страниц с отрисовкой, плавность, e-ink, iOS
- [ ] TalkBack / VoiceOver: проверка со скринридером на устройстве (`docs/ACCESSIBILITY.md`)
- [ ] Поиск по тексту внутри книги в читалке и горячая клавиша для него (сейчас клавиатурой работают листание, оглавление, закладка, пауза озвучки)
- [ ] Тексты служебных слоёв (статусы сканирования и скачивания, описания моделей, запросы к ИИ) — в ресурсы и на все языки

### Документация

- [ ] Обновлённые скриншоты в README (делаются вручную на устройствах)

### Вне плана

- DJVU: единственный зрелый декодер DjVuLibre распространяется под GPL, что несовместимо с MIT-лицензией проекта; свой декодер (JB2/IW44) — отдельный большой проект.
- Передача озвучки на Chromecast: невозможна без собственного сетевого протокола; системный выбор вывода звука (AirPlay, панель вывода Android) есть.
