# Проверка 2.8.0 на устройствах

## Автоматические проверки

- Android: `:androidApp:connectedDebugAndroidTest` запускает реальное приложение и системный
  `TextToSpeech`, проверяя переход к следующему предложению. CI использует эмулятор API 26 —
  это smoke-проверка, не замер слабого телефона.
- iOS: схема `LocalDocAI` содержит target `LocalDocAIUITests`; CI запускает UI-смоук на симуляторе.
- Полный JVM-suite: `:shared:testAndroidHostTest :androidApp:testDebugUnitTest`.

## Замер умного поиска

На физическом Android, подключённом по ADB:

```powershell
.\scripts\device-benchmark.ps1 -RequirePhysicalDevice
```

Скрипт ставит debug-приложение поверх debug-сборки без удаления данных, запускает
`SemanticSearchBenchmark`, сохраняет instrumentation log, `device.json` и JSON с временами
индексации/запросов и выборкой PSS/Java heap в `benchmark-results/<timestamp>/`.
Результат не передаётся никуда автоматически.

Это повторяемый замер полного конвейера RAG с hashing-провайдером, **не ONNX e5**: сетевой
скачивание и модель в тест специально не встроены. Поэтому он не является основанием для изменения
`SemanticModelPolicy.MAX_PASSAGE_MILLIS`. Для решения по e5 нужен отдельный замер на уже проверенной
и установленной модели с медианой реальных `encodePassage` и замеченным пиком PSS.

Эмуляторные результаты можно собрать для отладки методики без `-RequirePhysicalDevice`; в JSON
они помечаются `physicalDevice: false`. Их нельзя выдавать за приёмку слабых физических телефонов.

## Ручная приёмка

- Озвучить минимум три страницы: смена страницы, пауза/возобновление во время подготовки следующей,
  переход по предложению, таймер сна, звонок/аудиофокус и отключение наушников.
- Построить и перестроить RAG-индекс, отключить/включить e5 во время загрузки, удалить и снова
  установить модель; проверить поиск и отсутствие роста памяти после повторов.
- Сохранить сырой JSON и данные устройства до любого изменения порогов.

## Состояние приёмки

Локально на Windows проверяются JVM-тесты, компиляция Android device-тестов и сборка APK.
iOS-компиляция и UI-смоук доступны только на macOS/CI. Результаты физических слабых устройств
в репозитории отсутствуют до фактического запуска скрипта на таких устройствах.
