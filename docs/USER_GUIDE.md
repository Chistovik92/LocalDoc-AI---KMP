# Руководство LocalDoc AI

## Чтение

Откройте книгу из библиотеки или адрес страницы на вкладке «Веб». В меню «⋮» доступны оглавление, поиск, темы, шрифт и выбор режима «По страницам» или «Прокрутка». В постраничном режиме PDF показываются исходные страницы; текстовый режим и OCR сканов выбираются отдельно. Прогресс, закладки, цитаты и заметки сохраняются автоматически.

## Поиск

Поиск по библиотеке находит слова во всех проиндексированных книгах. Для смыслового поиска в настройках можно скачать multilingual-e5-small: модель работает локально, без передачи текста в сеть. На слабом устройстве приложение может оставить лексический поиск.

## Синхронизация и копии

В «Настройки → Синхронизация» укажите папку WebDAV и пароль шифрования. Один и тот же пароль шифрования нужен на каждом устройстве; восстановить его нельзя. Данные шифруются до отправки, пароли сайтов не синхронизируются.

Google Drive: введите OAuth Client ID своего Google Cloud-клиента для Desktop app, откройте вход, разрешите доступ к скрытой папке приложения и вставьте код. Синхронизируется только `localdoc-sync.ldsync` в appDataFolder, а не остальные файлы Drive. На iOS для iCloud нужен Apple ID, iCloud Drive и подпись с entitlement iCloud Documents; без этого контейнер может быть недоступен.

Резервная копия `.ldbackup` создаётся вручную или по расписанию и восстанавливается только после проверки целиком.

## Каталоги

Во вкладке каталогов сканируются выбранные папки, устройство и OPDS-серверы. Для защищённого OPDS укажите логин и пароль. Полки группируют книги по авторам, сериям, жанрам и другим признакам.

## Модели и NeuroCode

GGUF-модели скачиваются в разделе «Модели». На Android NeuroCode может получить список через `content://com.localdoc.ai.models` и скопировать выбранный файл через ContentProvider; сетевой повторной загрузки не требуется. Для других приложений доступен системный ACTION_SEND с временным разрешением только на чтение. Произвольные файлы и запись через этот интерфейс не разрешены.
