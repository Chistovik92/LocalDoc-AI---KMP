# История версий

Сюда записывается каждая новая версия LocalDoc AI: что добавлено, исправлено и изменено.
Новая версия добавляется **сверху**; раздел текущего релиза копируется в `.github/release-notes.md`
(его текст попадает в описание GitHub Release и в окно обновления в приложении).

## 1.6.5

Главное: **приложение само скачивает обновление**, главы веб-новелл собираются в одну книгу,
**виджет рабочего стола снова работает**, исправлены «расползающиеся» кнопки.

### Новое
- **Обновление внутри приложения** (Android): «Скачать и установить» теперь качает APK в самом
  приложении (прогресс, отмена, докачка после обрыва) и открывает системную установку поверх
  текущей версии — вместо перехода в браузер. При первом запуске система попросит разрешить
  установку из LocalDoc AI; файл уже скачан, останется нажать кнопку ещё раз.
- **Главы одной веб-новеллы — одна книга.** В «Книгах» главы одной новеллы на одном сайте собраны
  в одну плитку («3 главы»); по нажатию — список глав с прогрессом и отметкой последней открытой.
  Долгое нажатие удаляет все главы. «Продолжить чтение» показывает название новеллы и главу.
- Описание релиза в окне обновления показывается без Markdown-разметки.

### Исправлено
- **Виджет рабочего стола не загружался** («Невозможно загрузить виджет»): в разметке стоял
  недопустимый для виджетов элемент. Добавлено превью виджета в списке виджетов.
- Кнопки больше не сжимаются в круг и не ломают текст по буквам на узких экранах и при крупном
  шрифте («Слушать», «Далее →», «Настройки TTS» и др.) — кнопки переносятся целиком.
- Подсказки на вкладке «Веб» были белыми на белом, чип «Модель не выбрана» обрезался,
  карточки подсказок в «Ассистенте» не занимали всю ширину, подписи ИИ-кнопок в читалке обрезались.

### Технически
- `UpdateManager` на базе `ModelDownloader` (`updates/*.apk`), `FileProvider`, разрешение
  `REQUEST_INSTALL_PACKAGES`; устаревший APK установленной версии удаляется при проверке обновлений.
- Группировка глав — чистая функция `groupLibrary` без изменения формата хранения библиотеки.
- Тесты: группировка новелл, разбор релиза GitHub и очистка Markdown.

## 1.6.0

Главное: **встроенный офлайн-синтезатор речи** на открытых нейросетевых голосах Piper —
книги читаются естественным голосом без интернета и без установки сторонних TTS-движков.

### Новое
- **Встроенные голоса Piper** (sherpa-onnx, VITS): русские — Ирина, Денис, Дмитрий, Руслан;
  английские — Lessac, Amy, Ryan (US), Alan, Jenny (UK). Раздел «Встроенные голоса» в настройках
  озвучки: скачивание (около 65 МБ на голос, с докачкой после обрыва), прогресс, отмена, удаление.
- Выбор встроенного голоса сразу переключает плеер на новый движок; вернуться к системному
  синтезатору можно там же (в том числе на iOS).
- **Без пауз между фразами**: пока звучит предложение, следующее уже синтезируется.
- Скорость речи — средствами модели, высота голоса — при воспроизведении (AudioTrack / AVAudioEngine).

### Сохранено
- Пропуск фрагментов, которые не удалось озвучить, остановка с предупреждением в конце главы,
  подсветка читаемого предложения, плеер в шторке и на экране блокировки.

### Технически
- Android: AAR `sherpa-onnx-static-link-onnxruntime` 1.13.8 (JNI, onnxruntime внутри),
  Gradle берёт его из GitHub Releases; распаковка голосов — commons-compress (bzip2) и общий
  потоковый разбор tar с защитой от выхода за каталог голоса.
- iOS: `SherpaOnnxC.xcframework` 1.13.8 (C API через cinterop; sha256 проверяет скрипт
  `cpp_core/scripts/fetch_sherpa_onnx_ios.sh`), bzip2 — системная libbz2.
- Голоса — официальные сборки sherpa-onnx `tts-models` (модель .onnx + tokens.txt + espeak-ng-data).
- Загрузчик моделей обобщён: тот же код с докачкой качает и архивы голосов.

## 1.5.0

Главное: LocalDoc AI стал **читалкой** — книги всех популярных форматов и веб-страницы
в режиме чтения, озвучка с подсветкой предложения и локальный ИИ-суфлёр. Новый дизайн
в стиле Google (Material 3 / Material You).

### Новое
- **Читалка всех форматов**: EPUB (оглавление из NCX / nav), FB2 и FB2.ZIP (автор, разделы,
  стихи, эпиграфы, кодировка Windows-1251), PDF (текстовый слой + OCR, абзацы склеиваются
  из строк, переносы слов убираются), Markdown (заголовки, списки, цитаты, код, **жирный** / *курсив*),
  TXT (автоопределение UTF-8 / UTF-16 / Windows-1251, поиск глав), HTML.
- **Библиотека в стиле Google Play Книг**: обложки, «Продолжить чтение», поиск, фильтры по типу,
  прогресс чтения сохраняется для каждой книги, кэш разобранных книг (PDF не распознаётся повторно).
- **Экран чтения**: скрываемые панели (тап по тексту, прокрутка), 5 тем бумаги (авто, светлая,
  сепия, тёмная, ночь), шрифт с засечками / без, размер и межстрочный интервал, выравнивание
  по ширине, оглавление, ползунок прогресса.
- **ИИ-суфлёр в читалке**: «Суммаризировать страницу», «Объяснить термин», «Найти главное»
  в главе — ответ локальной модели в нижней шторке, продолжение диалога в «Ассистенте».
- **Вкладка «Веб»**: адресная строка в стиле Google, страница открывается как в браузере
  в режиме чтения (без рекламы и меню), недавние страницы доступны офлайн.
- **Веб-новеллы**: переход «Следующая / Предыдущая глава» (rel=next/prev, текст и классы ссылок),
  загрузка оглавления новеллы; если маркеров нет — нужную ссылку находит **локальная модель**.
- **Плеер озвучки**: плей / пауза / стоп, переходы на предложение и абзац назад/вперёд, подсветка
  читаемого предложения и автопрокрутка, тап по абзацу — читать с него; мини-плеер на всех вкладках.
- **Конец главы**: озвучка не переходит дальше сама — говорит «Конец главы» и ждёт пользователя
  (кнопки «Читать дальше» / «Следующая глава»).
- **Плеер в шторке** (Android): уведомление-медиаплеер с MediaSession — управление из шторки,
  с экрана блокировки и кнопками гарнитуры; чтение продолжается при свёрнутом приложении.
  iOS: «Пункт управления» и экран блокировки, фоновое воспроизведение.
- **Виджет рабочего стола**: Android — плеер (назад / плей-пауза / вперёд / стоп), «Открыть книгу»,
  «Ссылка», цвета Material You; iOS (WidgetKit) — «Слушать», «Книга», «Ссылка», «Продолжить».
- **Голоса и движки TTS**: выбор любого установленного движка (в т.ч. сторонних и открытых —
  RHVoice, sherpa-onnx с голосами Piper, eSpeak NG), выбор голоса, скорость и высота речи,
  установка голосовых данных; ссылки на открытые движки прямо в приложении.
- **Каталог моделей**: 15 GGUF-моделей для смартфонов — Qwen 2.5 / Qwen 3, Gemma 2 / Gemma 3,
  Llama 3.2, Phi 3.5, SmolLM2, DeepSeek R1 Distill, Vikhr (русский); новая страница с фильтром
  по ОЗУ, оценками качества / скорости / русского языка, лицензиями и рекомендациями.
  Для каждого семейства — свой шаблон диалога (ChatML, Llama 3, Gemma, Phi-3, DeepSeek),
  блок рассуждений `<think>` скрывается.
- **Обновления**: приложение само проверяет новые релизы на GitHub, показывает список изменений
  и скачивает APK (iOS — страница релиза).
- Открытие книг из проводника / «Файлов», «Поделиться» файлом, deep link `localdoc://`.

### Исправлено
- **Озвучка больше не останавливается на рекламе**: веб-страницы очищаются алгоритмом в духе
  Readability (рекламные и служебные блоки, маркировка «Реклама … erid» удаляются), текст читается
  целиком по предложениям — раньше озвучивались только первые 4000 символов, а сбой синтезатора
  на одном фрагменте обрывал чтение. Теперь сбойный фрагмент пропускается.
- Ссылка на Qwen 2.5 7B вела на несуществующий файл (официальный репозиторий перешёл на разбитые файлы).
- Android 11+: сторонние TTS-движки не были видны приложению (нет `<queries>` для TTS_SERVICE).

### Изменено
- Новый дизайн всего приложения: палитра и формы Google Material 3, динамические цвета обоев
  на Android 12+, «Ассистент» в стиле Gemini, вкладки «Книги · Веб · Ассистент · Модели».

## 1.1.0

### Исправлено
- **iOS собирается снова**: исправлены ошибки компиляции Kotlin/Native — непрозрачная
  C-структура сессии (`cnames.structs.LocalDocSession`), типизация ObjC-коллекций
  (Vision OCR, UIDocumentPicker), выбор голоса TTS без категорий `NSLocale`.
- **Краш на длинных запросах**: промпт декодируется порциями по `n_batch` — раньше любой
  запрос длиннее 512 токенов (почти любой RAG-запрос) завершал приложение через `GGML_ASSERT`.
- Запрос, не помещающийся в контекст модели, теперь возвращает понятную ошибку, а длина
  ответа ограничена оставшимся контекстом.
- **Кириллица в стриминге**: C-мост больше не отдаёт в UI оборванные UTF-8 последовательности.
- Android: токены передаются через JNI байтами — эмодзи и 4-байтовые символы больше
  не роняют процесс (Modified UTF-8 в `NewStringUTF`).
- Выгрузка/смена модели во время генерации больше не приводит к use-after-free:
  `localdoc_free` дожидается остановки генерации.
- Быстрые действия над документом и загрузки моделей больше не обрываются при смене вкладки;
  кнопка «Стоп» отменяет генерацию полностью.
- iOS: модели сохраняются в `Documents/models` (запись в корень песочницы невозможна),
  прогресс загрузки считается корректно, кнопка «Отменить» работает, делегат выбора файла
  больше не освобождается до выбора PDF.
- Докачка: если сервер игнорирует `Range` и отдаёт файл целиком, загрузка начинается заново
  вместо порчи модели; обрыв сети на Android показывает ошибку вместо вечного прогресса.
- После перезапуска приложения ранее выбранная модель загружается автоматически
  (раньше UI показывал «Загружена», хотя модель не была в памяти).
- RAG-индекс строится один раз на документ и вне главного потока; хранится не более
  5 последних индексов.
- iOS `KeyValueStore.clearAll()` очищает только домен приложения.

- Отмена генерации надёжна: stop() больше не теряется и не обрывает следующий ответ,
  prefill длинного документа прерывается между порциями, выгрузка модели не блокирует UI.
- iOS-проект: исправлены пути исходников в `project.yml`, симулятор собирается с debug-фреймворком,
  явно линкуются `libc++`, Metal и Accelerate.
- Android: убраны лишние разрешения `MANAGE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE`,
  отключён облачный бэкап данных приложения, текстовые файлы больше не отправляются в PDF-парсер,
  ссылка извлекается из «Заголовок + URL» при «Поделиться», имя PDF берётся из реального имени файла.

### Изменено
- **Постоянная подпись Android**: release-APK подписывается постоянным ключом (RSA 4096, до 2054 г.)
  вместо тестового. Ключ хранится вне репозитория, в CI передаётся через GitHub Secrets.
  ⚠️ Версия 1.0.0 подписана тестовым ключом — перед установкой 1.1.0 её нужно удалить (отдельной 1.0.1 не выпускалось, см. раздел «1.0.1»).
- Новый интерфейс: тема в цветах иконки, верхняя панель со статусом модели, чат с пузырями
  сообщений, подсказками, выделением текста и кнопкой «Стоп», баннер «Модель не загружена»,
  подсветка активной модели и процент загрузки.
- Новая иконка приложения (адаптивная + монохромная для Android 13+, AppIcon для iOS).

### Добавлено
- Unit-тесты `commonTest` (чанкер, эмбеддер, коды статуса генерации) и их запуск в Android CI.

## 1.0.1 — не выпускалась

Версия подготовлена в коде 2026-10-19 (коммит `61684e7`, `versionName = "1.0.1"`, `versionCode = 2`,
iOS `MARKETING_VERSION 1.0.1`), но **релиз не публиковался**: тега `v1.0.1` и GitHub Release нет.

Почему: сразу после неё iOS-сборка упёрлась в ошибки компиляции Kotlin/Native. Три следующих коммита
(`2614546`, `aef054f`, `dead8bc`) чинили сигнатуры ObjC-делегатов, PDFKit, AVFAudio, NSURLSession,
типы cinterop-сессии. Вместо публикации 1.0.1 всё накопленное вошло в **1.1.0** — поэтому записи 1.0.1
повторяются среди изменений 1.1.0 и ранее не публиковались отдельно.

### Что вошло (потом выпущено в 1.1.0)
- iOS: абсолютный include-путь для `localdoc_c_api.h` в cinterop; синхронизация через `SyncLock`
  (Android — `synchronized`, iOS — `NSLock`) вместо Java `synchronized`, недоступного в Kotlin/Native.
- Устойчивость: проверки сэмплера, URL и протокола загрузки, тела PDF, параметров чанкинга;
  корректная обработка `CancellationException`.
- Android: разрешения `READ_EXTERNAL_STORAGE` / `MANAGE_EXTERNAL_STORAGE` (убраны в 1.1.0 как лишние),
  иконки приложения, папка моделей в `getExternalFilesDir`.
- Интерфейс: тема, экран чата, анимации кнопок.
- CI: исправления сборки по результатам первых запусков.

## 1.0.0

Дата: 2026-10-19, тег `v1.0.0`. Первый релиз: кроссплатформенное приложение (Android + iOS) для анализа документов
и веб-страниц **полностью локальными** нейросетями — без облака и телеметрии.

### Возможности
- **Перехват из браузера**: «Поделиться» → LocalDoc AI — страница очищается от мусора (Reader Mode)
  и попадает в чат с моделью.
- **Документы**: PDF (текстовый слой + офлайн-OCR для сканов), TXT и Markdown.
  Android — PDFBox-Android + Google ML Kit; iOS — PDFKit + Apple Vision.
- **Локальные LLM**: каталог GGUF-моделей (Qwen 2.5, Llama 3.2) в 4-битном квантовании Q4_K_M,
  скачивание с Hugging Face с докачкой при обрыве.
- **Smart Router** (3 режима): короткий документ — целиком в контексте; Map-Reduce для больших документов;
  локальный RAG — векторный поиск по чанкам для вопросов по книгам и отчётам.
- **Быстрые действия**: выжимка в 5 тезисах, факты/цифры/даты, перевод и адаптация, объяснение простыми словами.
- **Локальный TTS**: озвучивание документов и ответов (системный синтезатор Android / `AVSpeechSynthesizer`).
- **Статистика**: скорость генерации (токенов/с) в интерфейсе.

### Технически
- Единое C-ядро на llama.cpp (подмодуль, тег `b10004`) с чистым C-интерфейсом `localdoc_c_api.h`:
  JNI + Vulkan/CPU на Android, cinterop + Metal на iOS.
- Kotlin Multiplatform + Compose Multiplatform, общий UI и бизнес-логика (`SmartPipeline`) в `commonMain`.
- RAG без нативных зависимостей: feature hashing (384 измерения), L2-нормализация, косинусный top-K поиск
  в JSON-хранилище; интерфейс `EmbeddingProvider` готов к замене на ONNX-модель.
- Загрузка весов через `mmap`; промпт-шаблон ChatML под Qwen 2.5 Instruct.
- CI (GitHub Actions): сборка Android APK и iOS-фреймворка; на тег `v*` — release-APK в GitHub Release.
  Три первых исправления CI вошли в тег: права `contents: write` для релиза, путь статических библиотек
  в скрипте XCFramework, `libtool` вместо `ar` для fat-архивов.

### Известные проблемы (исправлены в 1.1.0)
- В релизе только APK; iOS-приложение не публиковалось, а его сборка не проходила (ошибки Kotlin/Native).
- APK подписан **тестовым** CI-ключом, лежавшим в репозитории (`signing/localdoc.keystore`).
  С 1.1.0 подпись постоянная, ключ хранится вне репозитория — поверх 1.0.0 установить новую версию нельзя,
  приложение нужно удалить.
- Падение на запросах длиннее 512 токенов (почти любой RAG-запрос), оборванные UTF-8 последовательности
  кириллицы и эмодзи в стриминге, use-after-free при выгрузке модели во время генерации, порча модели при докачке.
  Полный список — в разделе 1.1.0.
