## 1.8.0

Главное: **данные пользователя** — цитаты и заметки в читалке, личный словарь, поиск по тексту всех книг и резервная копия одним файлом.

### Новое
- **Цитаты и заметки.** Выделите текст в читалке — вместо системного меню появится панель «Цитата», «Заметка», «Слово», «Копировать».
  Сохранённые места подсвечиваются в тексте. «⋮ → Цитаты и заметки» — список книги с переходом к месту, правкой заметки и удалением;
  «Настройки → Цитаты и заметки» — все книги сразу. Выделение работает в книгах и в сохранённых веб-главах (в режиме перевода сохранять нельзя —
  выделен переведённый текст, а не оригинал).
- **Привязка к месту, устойчивая к смене вёрстки.** Место хранится не в номере страницы, а как «глава + блок + смещение символа + фрагмент
  с окружением». Смена шрифта, размера страницы и режима чтения его не затрагивает; если книгу разобрали заново и блоки сдвинулись,
  место находится по самому тексту (при повторах фразы выбирается вхождение с тем же окружением), а если текст изменился — по главе
  и расстоянию от её начала. Так же теперь работают и новые закладки; старые (без якоря) продолжают открываться по номеру блока.
- **Словарь.** Выделите слово → «Слово»: локальная модель переводит его в контексте предложения на выбранный язык перевода и даёт
  короткое определение, значение можно поправить и сохранить в личный список («Настройки → Словарь»). Без загруженной модели значение
  вводится вручную. Повторное сохранение того же слова обновляет запись.
- **Выгрузка аннотаций.** Цитаты, заметки, закладки и слова книги — в Markdown (по главам, цитата с заметкой под ней) или в EPUB
  (читается в любой читалке, главы — разделы оглавления). Словарь целиком — в Markdown.
- **Поиск по тексту книг и каталогу.** Под полем «Поиск в библиотеке» появляется «Искать … в тексте книг»: ищутся все слова запроса
  в одном абзаце, окончания не важны («книга» находит «книги», «книгой»); результат открывает книгу на найденном месте. В тех же
  результатах — файлы каталога устройства (название, автор, серия, жанр). Индекс лежит на диске и обновляется по изменениям:
  заново читается только новая или изменённая книга, удалённая стирается.
- **Резервная копия.** «Настройки → Резервная копия»: библиотека (тексты и картинки книг, прогресс чтения), закладки, цитаты и заметки,
  словарь и настройки читалки, озвучки и перевода — одним файлом `.ldbackup`. Пароли и сессии сайтов, модели, голоса, кэш картинок и
  индекс в копию не входят. Восстановление сначала проверяет файл целиком (формат, версию, наличие всех книг), показывает, что внутри,
  и только после подтверждения заменяет данные; копия более новой версии формата или повреждённый файл отклоняются, данные не затрагиваются.

### Технически
- `notes/`: `TextAnchor` и `AnchorResolver` (создание и поиск якоря, в том числе для выделения через несколько абзацев), `AnnotationRepository`,
  `DictionaryRepository`, `AnnotationExport` (Markdown и EPUB через `BookExporter`), `WordSelection`.
- `search/`: `FullTextIndex` (обратный индекс «слово → блоки» по файлу на документ, манифест с подписями в KV, кэш из шести файлов в памяти),
  `LibrarySearch` (синхронизация с библиотекой и каталогом, ранжирование по числу совпавших блоков, фрагменты текста).
- `backup/`: `BackupService`, формат версии 1 — ZIP (`backup.json`, `kv/*`, `files/*`) без сжатия; имена файлов из архива проверяются,
  запись начинается только после полной проверки.
- Читалка: `SelectionContainer` с собственным `TextToolbar` (панель действий вместо системного меню); `Bookmark` получил необязательное поле `anchor`.
- Тесты: `TextAnchorTest` (смена размера страницы, пересборка книги, повторы фразы, правки текста, старые закладки, многоабзацное выделение),
  `AnnotationExportTest`, `FullTextIndexTest` (морфология, инкрементальность, перезапуск, повреждённый файл, каталог, ранжирование),
  `BackupTest` (круговая проверка, состав копии, замена данных, новая версия формата, повреждённые файлы, безопасные имена).

### Не вошло и перенесено в план
- Нажатие на подсвеченную цитату в тексте (открыть заметку) и цвета подсветки — 1.9.0.
- Сжатие резервной копии и копия по расписанию — 2.0.0 (вместе с замораживанием формата).

## 1.7.6

Главное: **бережное скачивание страниц** — сайты больше не принимают загрузку книги за атаку и не блокируют.

### Исправлено и улучшено
- **Сайты блокировали при скачивании новелл.** Раньше главы грузились пачками по 3 параллельно с паузой 250 мс.
  Теперь к каждому сайту запросы идут строго по одному, с паузой около 1,2 с и случайным разбросом ±30 %, чтобы запросы не шли «по метроному».
  Правило общее: оно действует для глав, картинок, оглавлений и входа на сайт. Разные сайты друг друга не ждут.
- **Ответы «слишком много запросов» (429) и «временно недоступно» (503).** Приложение читает `Retry-After`, ждёт и повторяет запрос
  (не больше двух раз, только для чтения страниц — формы входа не отправляются повторно; cookie из ответа уходят с повтором), а пауза для этого сайта удваивается и постепенно возвращается к обычной по мере успешных ответов.
  Если сайт просит подождать дольше минуты, приложение не ждёт впустую, а сообщает об этом.
- Главы скачиваются по одной, картинки — по две одновременно (раньше по четыре), повтор неудачной главы — через 2 с, 4 с (раньше 0,8 с).
- Скачивание целой новеллы стало медленнее — это сознательная плата за то, что сайт не заблокирует доступ. Уже скачанные главы по-прежнему
  не загружаются повторно.

### Технически
- `HostThrottle` (`net/`) — очередь запросов на каждый сайт с монотонными часами и подменяемыми ожиданием и случайностью;
  `WebHttp` проводит через неё каждый запрос, включая шаги редиректа.
- `NovelDownloader`: пачка глав 3 → 1, собственная пауза между пачками убрана (паузы выдерживает `WebHttp`).
- Тесты `HostThrottleTest`: интервал, независимость сайтов, `Retry-After`, лимит повторов, ответ дольше минуты, разбор заголовка.
- Не вошло и перенесено в план: настройка «Скорость скачивания» (1.11.0) и учёт `Crawl-delay` из `robots.txt` (1.11.0).

## 1.7.5

Главное: **скачивание книги целиком** (сайт отдаёт файл — берём его, нет — собираем по оглавлению, листать ничего не нужно),
**вход на сайты** с веб-новеллами, **автопереход «Далее»**, **каталог книг на устройстве** с полками по жанрам, авторам и годам,
**сохранение и конвертация** в EPUB, FB2, DOCX, ODT, RTF, TXT, HTML, Markdown и XML, новые форматы **RTF, XML, WPS, Pages**,
**обложки и картинки** во всех форматах и полное удаление рекламы.

### Новое
- **Скачать книгу целиком.** «⋮» в читалке или долгий тап по книге → «Скачать книгу целиком…». Приложение само ищет готовый
  файл (EPUB, FB2, DOCX…) на странице, в оглавлении и в объявленных альтернативах; если его нет — запрашивает страницу
  оглавления и загружает главы по списку, затем склеивает их в одну книгу с оглавлением. Прогресс, отмена, докачка
  (скачанные главы лежат в отдельной папке и не загружаются повторно), понятные ошибки. Реклама из глав убирается.
- **Вход на сайты.** Если страница закрыта логином, приложение предложит ввести логин и пароль или войти во встроенном
  браузере. Пароли — только в Android Keystore / iOS Keychain, cookie сессии зашифрованы, в резервные копии и логи
  ничего не попадает; «Настройки → Сайты и вход → Забыть сайт» стирает всё одним нажатием. Капчу и защиту сайта приложение
  **не обходит**: она показывается вам в окне браузера, а приложение лишь забирает итоговую сессию.
- **Автопереход.** «⋮ → Автопереход к следующей главе»: после озвучки (или прокрутки до конца) сама открывается следующая
  глава веб-новеллы, озвучка продолжается. Ссылку «Далее» при необходимости находит локальная модель.
- **Каталог книг на устройстве.** «Добавить → Найти книги на устройстве»: сканирование всего устройства (Android), папки,
  SD-карты, USB или облачной папки; полки как в интернет-магазинах — авторы, жанры, годы, серии, форматы, папки, языки,
  свои подборки; поиск, сортировка, добавление в библиотеку по одной книге или всей выборкой.
- **Сохранить как… / конвертация.** Любую книгу можно сохранить в EPUB, FB2, FB2.ZIP, DOCX, ODT, RTF, TXT, HTML,
  Markdown или XML — с заголовками, списками, выделениями, главами, обложкой и картинками.
- **Новые форматы:** RTF, XML (в том числе DocBook и Word 2003 XML), WPS, Pages, DOCM / DOTX / DOTM; формат определяется по
  расширению и по сигнатуре, бинарные файлы не принимаются за текст.
- **Обложки и картинки** (EPUB, FB2, DOCX, ODT, DOC, RTF, Pages, HTML, веб-страницы, Markdown): в читалке, библиотеке и
  экспорте; грузятся лениво и кэшируются на диске с ограничением размера.
- **Реклама убирается везде:** в веб-страницах, книгах любого формата и скачанных главах — вставки сайтов, водяные знаки,
  призывы подписаться, рекламные картинки.

### Исправлено и улучшено
- Повреждённые и обрезанные архивы (EPUB, DOCX, ODT, Pages) теперь дают понятное сообщение; добавлен тест с испорченными
  файлами всех форматов.
- Картинки декодируются вне главного потока и не раздувают память; cookie защищены от гонок при параллельной загрузке глав.
- Меню «Добавить» прокручивается при крупном шрифте; плашка загрузки читается в тёмной теме.

### Не проверено
- Реальные файлы Pages 2013+ (разбор по спецификации формата, проверен на собранных вручную данных) и WPS Works.
- Вход на конкретных сайтах: поведение проверено на имитации сервера; на iOS встроенный браузер и Keychain не запускались.

### Технически
- Новые модули `commonMain`: `RtfParser`, `XmlBookParser`, `WpsParser`, `PagesParser` (Snappy + protobuf), `ImageCollector`,
  `book/export` (EPUB, FB2, DOCX, ODT, RTF, TXT, HTML, Markdown, XML, `ZipWriter`), `net` (`WebHttp`, `CookieJar`,
  `SiteAuth`, `SiteVault`), `NovelDownloader`, `BookDownloadManager`, `ImageLoader`, `catalog` (`BookMetadata`,
  `CatalogRepository`, `CatalogQuery`).
- `expect/actual`: `RawHttp`, `SecureStore`, `FileSaver`, `DeviceScanner`, `LoginBrowser`, `decodeImageBitmap`,
  расширенный `FileAccess` (вложенные папки, список, удаление по префиксу).
- Модель `Book`: блоки-картинки, обложка, ресурсы; `HtmlBlockBuilder` сохраняет жирный / курсив / код.
- Тесты: форматы, картинки, круговые преобразования всех форматов, вход и cookie, скачивание (оглавление, докачка, готовый
  файл), каталог и полки, реклама, устойчивость к повреждённым файлам.

## 1.7.0

Главное: **перевод книг нейросетью «на лету»** и озвучка на любом языке, **постраничное чтение**
(большие книги больше не зависают), закладки, форматы **DOCX, DOC и ODT** и вкладка **«Настройки»**.

### Новое
- **Перевод на лету.** В читалке: меню «⋮» → «Перевод…» — страницы переводятся локальной моделью
  с любого языка на любой (33 языка, оригинал определяется автоматически). Соседняя страница
  готовится заранее, готовые страницы кэшируются; озвучка читает перевод. Автоперевод — в «Настройках».
- **Озвучка на любом языке.** Голос подбирается под язык текста или перевода: ваш выбор для языка →
  установленный голос Piper → системный голос языка. В каталог Piper добавлено более 20 языков
  (немецкий, французский, испанский, итальянский, португальский, польский, украинский, китайский и др.).
- **Постраничная подача.** Книга любого формата делится на страницы; в озвучку, перевод и ИИ-суфлёр
  подаётся только текущая страница (и следующая — для озвучки без пауз). В «Настройках → Чтение»
  выбирается режим: сплошная **прокрутка** или **по страницам**, а также размер страницы.
- **Закладки** в книгах и на веб-страницах / главах веб-новелл: значок закладки в читалке, список
  закладок книги, общий список в «Настройках»; нажатие открывает книгу на нужном месте.
- **Документы Word и OpenOffice**: `.docx`, `.doc` (Word 97–2003) и `.odt` — абзацы, заголовки,
  списки, таблицы, жирный и курсив; формат добавлен в выбор файла и в «Поделиться / Открыть в…».
- **Вкладка «Настройки»** вместо «Модели»: нейросети (экран выбора моделей без изменений), озвучка и
  голоса, перевод, оформление и режим чтения, закладки, обновления и «О приложении».

### Исправлено
- Большие документы (в том числе EPUB) не озвучивались: приложение зависало и падало, потому что весь
  текст разбирался на предложения разом. Теперь в работе одно «окно» из двух страниц.
- Файлы `.docx` не открывались (определялись как EPUB и давали ошибку разбора).
- `.doc` и другие бинарные файлы роняли приложение: читались как простой текст. Теперь формат
  определяется по сигнатуре (в том числе OLE2), бинарные данные не принимаются за текст, а на
  любой неразобранный файл приложение отвечает понятным сообщением вместо вылета.
- Подсказка в списке голосов «Только русские» больше не включена по умолчанию.

### Технически
- Новые чистые модули в `commonMain`: `Ole2File` / `DocParser` / `DocxParser` / `OdtParser`,
  `FormatDetector.resolve`, `BookPager`, `PageTranslator`, `LanguageDetector`, `VoiceSelector`,
  `BookmarkRepository`; `ReadAloudController` работает с окном страниц (`SpeechPageSource`).
- Тесты: форматы Word/ODT и устойчивость к битым файлам, постраничная озвучка, перевод, закладки,
  подбор голоса, определение языка.

## 1.6.5

Главное: **приложение само скачивает обновление**, главы веб-новелл собираются в одну книгу,
**виджет рабочего стола снова работает**, исправлены «расползающиеся» кнопки.

### Новое
- **Обновление внутри приложения** (Android): «Скачать и установить» теперь качает APK в самом
  приложении (прогресс, отмена, докачка после обрыва) и открывает системную установку поверх
  текущей версии — вместо перехода в браузер. При первом запуске система попросит разрешить
  установку из LocalDoc AI; файл уже скачан, останется нажать кнопку ещё раз.
- **Главы одной веб-новеллы — одна книга.** В «Книгах» главы одной новеллы на одном сайте собраны
  в одну плитку («3 главы»); по нажатию — список глав с прогрессом и отметкой последней открытой.
  Долгое нажатие удаляет все главы. «Продолжить чтение» показывает название новеллы и главу.
- Описание релиза в окне обновления показывается без Markdown-разметки.

### Исправлено
- **Виджет рабочего стола не загружался** («Невозможно загрузить виджет»): в разметке стоял
  недопустимый для виджетов элемент. Добавлено превью виджета в списке виджетов.
- Кнопки больше не сжимаются в круг и не ломают текст по буквам на узких экранах и при крупном
  шрифте («Слушать», «Далее →», «Настройки TTS» и др.) — кнопки переносятся целиком.
- Подсказки на вкладке «Веб» были белыми на белом, чип «Модель не выбрана» обрезался,
  карточки подсказок в «Ассистенте» не занимали всю ширину, подписи ИИ-кнопок в читалке обрезались.

  `localdoc_free` дожидается остановки генерации.

- После перезапуска приложения ранее выбранная модель загружается автоматически

## 1.0.0

Дата: 2026-10-19, тег `v1.0.0`. Первый релиз: кроссплатформенное приложение (Android + iOS) для анализа документов
и веб-страниц **полностью локальными** нейросетями — без облака и телеметрии.

### Возможности
- **Перехват из браузера**: «Поделиться» → LocalDoc AI — страница очищается от мусора (Reader Mode)
  и попадает в чат с моделью.
- **Документы**: PDF (текстовый слой + офлайн-OCR для сканов), TXT и Markdown.
  Android — PDFBox-Android + Google ML Kit; iOS — PDFKit + Apple Vision.
- **Локальные LLM**: каталог GGUF-моделей (Qwen 2.5, Llama 3.2) в 4-битном квантовании Q4_K_M,
  скачивание с Hugging Face с докачкой при обрыве.
- **Smart Router** (3 режима): короткий документ — целиком в контексте; Map-Reduce для больших документов;
  локальный RAG — векторный поиск по чанкам для вопросов по книгам и отчётам.
- **Быстрые действия**: выжимка в 5 тезисах, факты/цифры/даты, перевод и адаптация, объяснение простыми словами.
- **Локальный TTS**: озвучивание документов и ответов (системный синтезатор Android / `AVSpeechSynthesizer`).
- **Статистика**: скорость генерации (токенов/с) в интерфейсе.

### Технически
- Единое C-ядро на llama.cpp (подмодуль, тег `b10004`) с чистым C-интерфейсом `localdoc_c_api.h`:
  JNI + Vulkan/CPU на Android, cinterop + Metal на iOS.
- Kotlin Multiplatform + Compose Multiplatform, общий UI и бизнес-логика (`SmartPipeline`) в `commonMain`.
- RAG без нативных зависимостей: feature hashing (384 измерения), L2-нормализация, косинусный top-K поиск
  в JSON-хранилище; интерфейс `EmbeddingProvider` готов к замене на ONNX-модель.
- Загрузка весов через `mmap`; промпт-шаблон ChatML под Qwen 2.5 Instruct.
- CI (GitHub Actions): сборка Android APK и iOS-фреймворка; на тег `v*` — release-APK в GitHub Release.
  Три первых исправления CI вошли в тег: права `contents: write` для релиза, путь статических библиотек
  в скрипте XCFramework, `libtool` вместо `ar` для fat-архивов.

### Известные проблемы (исправлены в 1.1.0)
- В релизе только APK; iOS-приложение не публиковалось, а его сборка не проходила (ошибки Kotlin/Native).
- APK подписан **тестовым** CI-ключом, лежавшим в репозитории (`signing/localdoc.keystore`).
  С 1.1.0 подпись постоянная, ключ хранится вне репозитория — поверх 1.0.0 установить новую версию нельзя,
  приложение нужно удалить.
- Падение на запросах длиннее 512 токенов (почти любой RAG-запрос), оборванные UTF-8 последовательности
  кириллицы и эмодзи в стриминге, use-after-free при выгрузке модели во время генерации, порча модели при докачке.
  Полный список — в разделе 1.1.0.
